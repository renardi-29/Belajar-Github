# Belajar Git & GitHub 🚀

Repository ini adalah project latihan pertama saya untuk mempelajari Git dan GitHub secara bertahap.

## 📖 Tentang Project

Project ini merupakan website sederhana yang saya gunakan untuk mendokumentasikan perjalanan belajar Git dan GitHub.

Di dalam proses pembuatannya, saya mempraktikkan berbagai konsep dasar Git, mulai dari repository, commit, branch, merge, conflict, hingga pull request dan GitHub Pages.
